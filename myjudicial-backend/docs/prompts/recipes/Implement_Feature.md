# Implement Feature

Read:

- Project Onboarding
- Feature Playbook
- Feature Checklist
- API Checklist
- Security Checklist
- Master Build Reference
- Audit Report
- Implementation Roadmap
- Requested Feature Specification

Steps

1. Review existing implementation.

2. Identify reusable code.

3. Produce implementation plan.

4. Wait for approval.

5. Implement incrementally.

6. Complete Feature Checklist.

7. Run Code Review.

8. Apply Refactoring.

9. Produce completion report.
